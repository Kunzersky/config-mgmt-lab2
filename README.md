# Визуализатор зависимостей Cargo

CLI-приложение для анализа зависимостей Rust-пакетов из crates.io или
локального тестового графа. Проект выполняется по этапам практической работы
№ 2, вариант 12.

## Текущий этап

Этап 1: CLI принимает настройки и выводит их в формате `ключ=значение`.

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--package` | Имя анализируемого пакета; обязательно. |
| `--repository` | URL crates.io либо путь к JSON-графу. |
| `--test-mode` | Включить работу с локальным графом. |
| `--output` | Имя выходного SVG; по умолчанию `dependencies.svg`. |
| `--tree` | Включить вывод зависимостей в виде ASCII-дерева. |
| `--filter` | Исключить пакеты, в имени которых есть подстрока. |

## Запуск и тесты

```sh
./run.sh --package serde --repository https://crates.io
python3 -m unittest discover -s tests
```

Программа сообщает об ошибке при неверном имени пакета, URL, тестовом пути
или расширении выходного файла. Дополнительные этапы будут расширять эту
команду, сохраняя те же параметры.
